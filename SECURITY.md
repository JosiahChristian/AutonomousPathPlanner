# Security Policy

## Supported version

Security fixes are applied to the latest revision of `main`.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately through the contact method listed on the GitHub profile.

Include the affected component, reproduction conditions, potential impact, and any suggested mitigation. Reports will be evaluated for applicability to this demonstration software.

## Scope clarification

AutonomousPathPlanner is an educational engineering project, not certified safety-critical navigation software. Its outputs must not be used as the sole control authority for physical systems.
